# Documentation Rules

Dokumentasi project menggunakan Bahasa Indonesia; identifier kode mengikuti convention project.

Untuk perubahan signifikan perbarui PROJECT_PLAN.md, ARCHITECTURE.md, DATABASE.md, API.md, SECURITY.md, TESTING.md, SEO.md, dan CHANGELOG.md sesuai relevansi.

Dokumentasikan tujuan, keputusan, alasan, trade-off, risiko, testing, dan hal yang belum diverifikasi. Jangan mencatat PASS jika pemeriksaan belum dijalankan.
