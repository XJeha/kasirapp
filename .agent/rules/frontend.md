# Frontend Rules

Frontend harus production-ready, responsive, accessible, dan konsisten.

Pertimbangkan loading, success, empty, error, disabled, hover, focus, dan active state.

Verifikasi viewport representatif: 360, 390, 768, 1024, 1280, 1440+ px. Periksa overflow, clipping, navigation, form, modal, table, typography, image, dan long content.

Gunakan semantic HTML, keyboard accessibility, visible focus, label form, heading hierarchy, accessible names, alt text, dan contrast yang memadai. Pertahankan design system existing.
