# SEO Rules

Prioritaskan technical SEO berbasis standard terbuka dan tanpa biaya tambahan.

Periksa title, meta description, canonical, robots, sitemap, semantic HTML, heading hierarchy, internal links, descriptive URL, alt text, Open Graph, structured data, indexability, LCP, INP, dan CLS bila relevan.

Dilarang keyword stuffing, cloaking, hidden SEO text, doorway pages, fake structured data, dan spam pages.
